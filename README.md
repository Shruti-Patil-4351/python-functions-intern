##python-functions-intern
Short overview This repo contains exercises covering Python functions: definition, parameters, *args/**kwargs, lambdas, higher-order functions, recursion, decorators, and edge cases.

How to run tests

Create a virtual environment: python -m venv .venv source .venv/bin/activate # on Windows: .venv\Scripts\activate
Install requirements: pip install -r requirements.txt
Run tests: pytest -q
Structure:

src/: source files
tests/: pytest unit tests
solutions/: (optional) reference solutions after submission
